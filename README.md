## GitHub Pages setup

1. Use your actual GitHub username, which may differ from your UW NetID.
2. Open the repository named `JosiahTupufiaEnguerra.github.io`.
3. Upload the **contents** of this folder to the repository root: `index.html`, `README.md`, and `.nojekyll`. Include `resume.pdf` once ready. Do not upload just the ZIP or a parent folder.
4. Commit the changes.
5. In Settings → Pages, choose Deploy from a branch, then `main` and `/ (root)`, and save.
6. Open `https://JosiahTupufiaEnguerra.github.io` after deployment completes.
7. Test navigation, every external link, the resume download, and mobile layout. Confirm the published page matches the reviewed draft.
